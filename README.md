# Avito_Search_Ranking

Решение задачи поиска объявлений услуг Авито: word TF-IDF, char TF-IDF, учёт локации, CatBoostClassifier, RRF и валидация Recall@50.

# Поиск объявлений услуг Авито

Решение задачи подбора до 50 релевантных объявлений по пользовательскому запросу.

## Подход

1. Тексты нормализуются: приводятся к нижнему регистру, очищаются от лишних символов и смешения похожих русских и латинских букв.
2. Для поиска используются word TF-IDF по заголовку, параметрам и описанию и char TF-IDF по заголовку.
3. Кандидаты собираются с разными весами совпадения локации запроса и объявления.
4. CatBoostClassifier оценивает кандидатов по текстовому сходству, локации, категории, цене, рейтингу и другим признакам.
5. Текстовое ранжирование и предсказания CatBoost объединяются через взвешенный RRF.
6. Качество проверяется по Recall@50 на 1 000 запросах. Все строки с текстами валидационных запросов исключаются из обучения CatBoost.

## Результат

Лучший локальный результат: Recall@50 около 0.7829.

Лучшие настройки: вес CatBoost в RRF — 0.5, множитель совпадения локации — 16. Настройки подбирались на той же валидации.

Результат на Stepik: **0.738** против **0.690** у baseline.
